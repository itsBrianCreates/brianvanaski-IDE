# Claude Code Workflows

**Building with a team of AI digital workers.**

## The setup

I run a small team of AI agents using Claude Code. Not one agent doing everything -- a structured team, each with a role. One writes code. One reviews it. One generates content. One manages tasks. They coordinate through a system I call Cowork.

It sounds like science fiction, but it's just good workflow design applied to AI.

## How it works

Each agent has a defined scope, memory, and set of instructions. They hand off work to each other, flag blockers, and produce output I can review and ship. I'm the creative director. They're the studio.

The key insight: AI agents are dramatically more useful when they have constraints, context, and a clear job to do. An agent that does "anything" does nothing well. An agent that writes dad jokes for a specific app? That one delivers.

## What I've learned

- Structure matters more than power. A well-scoped agent beats a general-purpose one every time.
- AI agents are multipliers, not replacements. I still make every decision. I just move 10x faster.
- Building in public with AI tools is the best way to learn what actually works.

## Tools

Primarily Claude Code, with supporting scripts in Node.js and integrations with Firebase, GitHub, and the App Store toolchain.
