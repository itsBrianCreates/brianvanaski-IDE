# Live Coding + Music

**What happens when code makes sound.**

## The idea

Live coding is a performance art where you write code that generates music in real time. No pre-recorded tracks. No DAW. Just a text editor, a runtime, and whatever your brain comes up with on the fly.

I started experimenting with this as a creative outlet -- a way to use code that has absolutely nothing to do with product design or shipping features. Just pure play.

## What I'm exploring

- Algorithmic composition using code as the instrument
- Real-time audio synthesis driven by live-edited scripts
- The overlap between creative coding and musical improvisation

## Why it matters (to me)

Design work is intentional. Every pixel has a reason. Live coding music is the opposite -- it's generative, unpredictable, and messy in the best way. It keeps the creative muscles loose.

## Status

Ongoing experiment. No plans to perform at Coachella. Yet.
