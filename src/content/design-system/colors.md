# Colors

## Accent

- **Primary Accent:** `#FFD60A` — Apple system yellow. Warm, bright, impossible to ignore.
- **Light Theme Link:** `#CCB008` — Darker variant for readability on light backgrounds.

## Dark Theme

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-editor` | `#111111` | Main content background |
| `--bg-sidebar` | `#1a1a1a` | Sidebar and tab bar |
| `--bg-tab-active` | `#111111` | Active tab matches editor |
| `--bg-status` | `#2a2520` | Status bar, warm undertone |
| `--text-heading` | `#ffffff` | Headings, active labels |
| `--text-body` | `#e6e6e6` | Body text, ~90% white |
| `--text-muted` | `#808080` | Secondary text, line numbers |
| `--border-color` | `#3c3c3c` | Borders, dividers |
| `--hover-bg` | `#2a2d2e` | Hover states |
| `--active-bg` | `#37373d` | Active/selected states |

## Light Theme

| Token | Value | Usage |
|-------|-------|-------|
| `--bg-editor` | `#ffffff` | Main content background |
| `--bg-sidebar` | `#f3f3f3` | Sidebar and tab bar |
| `--text-heading` | `#000000` | Headings |
| `--text-body` | `#333333` | Body text |
| `--text-muted` | `#999999` | Secondary text |
| `--border-color` | `#e0e0e0` | Borders, dividers |
