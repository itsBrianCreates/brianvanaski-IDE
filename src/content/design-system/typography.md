# Typography

## Fonts

- **Monospace:** JetBrains Mono — used for the file tree, tabs, status bar, code view, and all UI chrome. Loaded from Google Fonts.
- **Body (Preview mode):** System sans-serif stack — `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`. Clean and native-feeling.

## Scale

| Element | Size | Weight | Font |
|---------|------|--------|------|
| Sidebar header | 13px | 600 | JetBrains Mono |
| File tree items | 13px | 400 | JetBrains Mono |
| Tabs | 12px | 400 | JetBrains Mono |
| Breadcrumb | 12px | 400 | JetBrains Mono |
| Status bar | 11px | 400 | JetBrains Mono |
| Preview body | 16px | 400 | System sans-serif |
| Preview h1 | 2em | 700 | System sans-serif |
| Preview h2 | 1.5em | 700 | System sans-serif |
| Preview h3 | 1.25em | 700 | System sans-serif |
| Code view | 14px | 400 | JetBrains Mono |
| Line numbers | 13px | 400 | JetBrains Mono |

## Line Height

- Preview body: `1.7` — generous for readability
- Code view: `1.6`
- UI elements: `22px` fixed
