# Spacing

Base unit: **4px**. All spacing uses multiples of 4.

## Scale

| Token | Value | Usage |
|-------|-------|-------|
| `4px` | 4px | Tight gaps (hamburger lines, chevron padding) |
| `8px` | 8px | Small gaps (tab close button padding) |
| `12px` | 12px | Sidebar header padding, status bar padding |
| `16px` | 16px | Standard padding (tabs, toolbar, content gaps) |
| `24px` | 24px | Section spacing, preview padding (mobile) |
| `32px` | 32px | Preview content padding (desktop) |
| `48px` | 48px | Preview horizontal padding (desktop) |
